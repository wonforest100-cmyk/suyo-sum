# 청소년국 결과보고서 제작실

원불교 청소년국의 1년 사업 결과보고서를 여러 담당자가 함께 쓰고, 그대로 **A4 인쇄·PDF**로 뽑는 웹 페이지입니다.
「2019 희망캠프 결과보고서」 양식(표지 → 목차 → 간지 → Ⅰ. / 1. / □ / ○ 개조식 본문, 좌우 교차 쪽번호)을 따릅니다.

- **파일 하나(index.html)** 로 동작합니다. 설치·빌드가 필요 없습니다.
- Supabase를 연결하기 전에는 **로컬 모드**(이 브라우저에만 저장)로 바로 써 볼 수 있습니다.
- Supabase를 연결하면 로그인, 파트별 권한, 실시간 반영, 편집 잠금, 댓글, 버전 기록이 켜집니다.

---

## 1. 바로 써 보기 (로컬 모드)

`index.html`을 크롬이나 엣지로 열면 예시 보고서가 들어 있습니다.
설정 > 데이터 > **빈 보고서로 시작** 을 누르면 예시를 지우고 새로 시작합니다.

> 로컬 모드는 이 컴퓨터의 이 브라우저에만 저장됩니다. 사진이 많으면 저장 공간(약 5MB)이 모자랄 수 있으니
> 함께 쓰거나 사진을 많이 넣을 때는 아래처럼 Supabase를 연결하세요. 언제든 **백업 파일(JSON) 받기**로 보관할 수 있습니다.

## 2. Supabase 연결 (공동 작업)

1. [supabase.com](https://supabase.com) 에서 새 프로젝트를 만듭니다 (무료 플랜 가능, 지역은 Seoul 권장).
2. 왼쪽 **SQL Editor** > New query 에 `supabase/schema.sql` 내용을 모두 붙여넣고 **Run**.
3. **Authentication > Sign In / Providers > Email** 이 켜져 있는지 확인합니다.
   - 가입 확인 메일 없이 바로 쓰려면 *Confirm email* 을 끕니다.
   - 이메일 링크 로그인을 쓰려면 **Authentication > URL Configuration** 의 Site URL에 GitHub Pages 주소를 넣습니다.
4. **Project Settings > API** 에서 `Project URL` 과 `anon public` 키를 복사합니다.
5. `index.html` 맨 위의 두 줄에 넣습니다.
   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJ...';
   ```
   (anon 키는 공개되어도 되는 키입니다. **service_role 키는 절대 넣지 마세요.**)
   파일을 고치기 어렵다면 페이지의 **설정 > 협업 연결**에 입력해도 됩니다. 이 경우 각자 브라우저에서 한 번씩 입력해야 합니다.

### 처음 로그인 순서
- **가장 먼저 가입한 사람이 관리자**가 됩니다. 국장님이나 총괄 담당자가 먼저 가입하세요.
- 이후 가입한 사람은 ‘열람’으로 시작합니다. 관리자가 **설정 > 구성원·권한**에서 역할과 담당 파트를 정합니다.

| 역할 | 할 수 있는 일 |
|---|---|
| 관리자 | 모든 보고서 편집, 사업 삭제, 파트 이동, ‘확정’ 처리, 보고서 설정·구성원 관리 |
| 작성자 | 담당 파트(또는 전체)의 보고서 편집, 사업 추가, 댓글, 버전 저장 |
| 열람 | 읽기, 댓글 |

- 로컬 모드에서 작성해 둔 내용이 있다면 연결 뒤 **설정 > 이 브라우저의 로컬 데이터를 Supabase로 올리기**를 누르세요.
- 관리자는 로그인 후 사업이 하나도 없으면 편집 화면의 **예시 데이터 넣기**로 예시를 넣어 볼 수 있습니다.

## 3. GitHub Pages로 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다 (`index.html`, `supabase/`, `.github/`, `README.md`).
2. 저장소 **Settings > Pages** > Source: *Deploy from a branch*, Branch: `main` / `(root)` > Save.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다. 이 주소를 팀에 공유하세요.

### Supabase 휴면 방지 (무료 플랜)
무료 플랜은 7일 동안 사용이 없으면 일시 정지됩니다. 저장소 **Settings > Secrets and variables > Actions** 에
`SUPABASE_URL`, `SUPABASE_ANON_KEY` 를 등록하면 `.github/workflows/keepalive.yml` 이 3일마다 자동으로 깨워 줍니다.
(Actions 탭에서 *Run workflow* 로 바로 시험할 수 있습니다.)

## 4. 사용법

### 보고서 구조
```
표지 → 발간사 → 목차(자동)
청소년국 총괄  : 간지 → 연간 사업 총괄(자동: 사업 일람표·월별 현황·예결산 총괄표·파트별 참가 인원) → 공통 사업들
제1부 어린이   : 간지 → 사업별 [간지 → 본문]
제2부 학생     : …
제3부 대학생   : …
```
목차, 쪽번호, 표 번호 `<표 n>`, 그림 번호 `<그림 n>`, 대단원 번호 Ⅰ·Ⅱ와 중단원 번호 1·2는 모두 자동입니다.

### 편집 단축키
| 키 | 동작 |
|---|---|
| Enter | 다음 줄(같은 단계) · 대단원 다음은 중단원, 중단원 다음은 □ |
| Shift+Enter | 같은 블록 안에서 줄바꿈 |
| Tab / Shift+Tab | 단계 내리기·올리기 (Ⅰ → 1. → □ → ○ → - → ※) |
| 빈 줄에서 `/` | 블록 메뉴 (표·일정표·예결산표·사진·차트·쪽 나눔 등) |
| Alt+↑ / Alt+↓ | 블록 위아래 이동 |
| Ctrl+B | `**굵게**` 표시 |
| Ctrl+Z | 구조 되돌리기 (블록 추가·삭제·이동) |
| Ctrl+F / Ctrl+P / Ctrl+S | 찾기·바꾸기 / 인쇄·PDF / 즉시 저장 |

- 한글 문서에서 `□ ○ - ※ Ⅰ. 1.` 로 쓴 개조식 글을 복사해 붙여넣으면 **단계가 자동으로 인식**됩니다.
  `○ 장소 : 익산성지`처럼 쓴 줄은 ‘항목 : 내용’ 블록이 되고, 인쇄할 때 항목명을 균등배분해 콜론을 세로로 맞춥니다.
- 표 칸에 엑셀·한글 표를 붙여넣으면 자동으로 채워집니다. 칸에 `<` 를 넣으면 왼쪽 칸과, `^` 를 넣으면 위 칸과 병합됩니다.
- 예결산표는 구분별 소계, 잔액, 증감, 집행률을 자동으로 계산하고, 연간 예결산 총괄표에 자동으로 더해집니다.
- 차트는 ‘설문 응답 자동 집계’로 바꾸면 설문 응답 열을 붙여넣기만 해도 응답별 개수를 세어 그립니다.
- 사진은 자동으로 크기를 줄여 저장합니다. 한 줄에 1~4장씩 배치할 수 있습니다.

### 자동 줄맞춤·쪽나눔
- 내용이 쪽을 넘으면 자동으로 다음 쪽으로 넘깁니다. 문단은 줄 단위로 나누고, 한 줄만 따로 남지 않게 합니다.
- 제목이 쪽 맨 아래에 혼자 남지 않게 합니다.
- 표가 넘어가면 **머리행을 반복**하고 캡션에 ‘(계속)’을 붙입니다. 마지막 한 행만 다음 쪽에 남지 않게 조정합니다.
- 오른쪽 **쪽 미리보기**의 **한 쪽 줄이기**는 행간·간격·사진 크기를 조금씩 줄여 쪽 수를 1쪽 줄여 봅니다 (촘촘하게 0~3단계).
- 쪽보다 큰 요소는 빨간 테두리, 쪽 너비보다 넓은 표는 주황 테두리로 표시하고 **점검** 탭에 목록으로 보여 줍니다.

### 인쇄 · PDF
**인쇄 · PDF** 버튼을 누르고 범위(전체 / 파트 / 사업 / 쪽 범위)를 고른 뒤 인쇄 창에서
**대상: PDF로 저장**, 용지 **A4**, 여백 **없음**, **배경 그래픽** 켜기, 배율 **100%** 로 맞추세요. (크롬·엣지 권장)
양면 인쇄·제본을 한다면 설정에서 **제본 여백**과 **간지를 홀수쪽에서 시작**을 켜세요.

### 협업 기능
- **실시간 반영**: 다른 사람이 저장한 내용이 바로 보입니다. 왼쪽 목록에 지금 누가 어떤 보고서를 보고 있는지 표시됩니다.
- **편집 잠금**: 한 보고서는 한 사람만 편집합니다. 다른 사람은 읽기 전용으로 보이고, 3분 동안 손을 대지 않거나 다른 보고서로 옮기면 잠금이 풀립니다.
- **진행 현황**: 사업별 담당자·마감일·상태(미작성 → 작성 중 → 검토 요청 → 수정 요청 → 확정)와 쪽수를 한눈에 봅니다. ‘확정’된 보고서는 관리자만 수정할 수 있습니다.
- **댓글**: 블록에 연결해 검토 의견을 남기고 ‘해결’ 처리합니다.
- **버전**: 검토 요청 전·확정 전에 버전을 저장해 두면 언제든 되돌릴 수 있습니다.

### 표기 점검
두 칸 띄어쓰기, 문장부호 앞 빈칸, ‘원기111년’ 띄어쓰기, **날짜와 요일이 맞는지**(예: 7월 26일(금) → 그해 요일 확인),
표기 사전(설정에서 편집), 빈 항목, 사진 설명 누락을 찾아 주고, 고칠 수 있는 항목은 한 번에 고칩니다.
**날짜·원기** 도우미로 `7월 26일(금) ~ 28일(일)` 형식의 날짜와 원기·서기 변환을 넣을 수 있습니다.
